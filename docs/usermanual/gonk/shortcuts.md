# Keyboard Shortcuts

### Custom Brush Shortcuts

- `B` = create custom brush. Drag area to create a custom bush.
- `Shift + B` = Restore Custom brush to original shape. Undo outline etc.
- `O` = Outline a Custom bush with the currently selected colour.
- `H` = Half the size of a Custom Brush
- `X` = Flip Custom Bush horizontally
- `Alt + X` = Change Custom Brush Handle (Cycle Corners + Centre)
- `Y` = Flip Custom Brush Vertically
- `Z` = Rotate Custom Brush 90 Degrees

### Bob/Sprite Editing

- `1` = Go to previous Bob/Sprite
- `2` = Go to next Bob/Sprite
- `Shift + 1` = Go to first Bob/Sprite
- `Shift + 2` = Go to last Bob/Sprite
- `3` = Go to Bob selector
- `` ` `` (Backtick) = Enable/Disable Bob Mask Editing
- `Numeric Arrow Keys` = Resize Cut Bob Box. `8 (UP), 2 (DOWN), 4 (LEFT), 6 (RIGHT)`

### Draw Modes

- `F1` = Matte
- `F2` = Colour
- `F3` = Replace
- `F5` = Shade
- `F7` = Cycle
- `F8` = Smooth

### Other

- `Arrow Keys [Up, Down, Left, Right]` = Scroll the Project window
- `M` = Magnify
  - `-` = Zoom Out
  - `+` = Zoom In
- `.` (dot) = Use the smallest dot brush
- `,` (comma) = Pick colour. Click mouse to select colour under pointer.
- `G` = Enable Cursor Gridlock. Snap to 8x8 Grid
- `D` = Dump Pens
- `J` = ActivateNextProjWindow(pj);
- `P` = Use Project Settings. Setup the screen so that the project is displayed in the right palette, at the right depth, using the right screen mode (depending on the KeepScreenMode flag).
